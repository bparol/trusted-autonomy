# Trusted Autonomous Systems

Public research on systems where autonomous software can understand context,
receive bounded authority, perform consequential actions, and remain
controllable. Two tracks, enterprise and financial, share one trust layer:
identity, authority, policy, delegation, verification, audit, control, recovery.

Layout and working rules are in [CLAUDE.md](CLAUDE.md).
